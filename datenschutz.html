KI-Telefonassistenz

Für diesen Telefonweg ist der STRATO KI-Telefonassistent genannt. Mega Clean Berlin beschreibt damit den eigenen Anschluss. STRATO ist der genannte Anbieter. Zweck ist die Entgegennahme der Anrufe, rund um die Uhr.

Hosting

Diese Website wird bei GitHub Pages ausgeliefert. Beim Besuch protokolliert GitHub die IP-Adresse und speichert sie zu Sicherheitszwecken, auch ohne Anmeldung bei GitHub. Die Speicherdauer legt GitHub fest. Quelle: GitHub-Dokumentation „About GitHub Pages“, Abschnitt Data collection.

Ein späteres Hosting bei STRATO für megacleanberlin.de ist nicht dieser Betrieb. GitHub Pages führt kein PHP aus.

Speicherung im Browser

Diese Website setzt keine Cookies. Sie lädt keine Schriften, Karten oder Skripte von anderen Servern. Die Schrift Plus Jakarta Sans liegt in der Datei fonts/PlusJakartaSans.woff2 auf demselben Host.

Der Tab speichert im sessionStorage den Schlüssel mc-tropfen-gesehen mit dem Wert 1. Zweck: das Ladezeichen nur einmal je Tab zeigen. Der Eintrag endet mit dem Tab. Kontaktdaten stehen darin nicht.

Die Seite kundenformular.html speichert Entwürfe der dort eingegebenen Antworten im localStorage unter dem Schlüssel megaclean-kundenformular, bis die Browserdaten dieser Seite gelöscht werden. Sie sendet die Entwürfe nicht an einen Server.

Kontaktformular

Das Formular ist noch nicht freigeschaltet und sendet nichts. Wenn es freigeschaltet ist, überträgt es Name, E-Mail, eine freiwillige Telefonnummer und die Nachricht an info@megacleanberlin.de über einen eigenen PHP-Endpunkt auf dem dann betriebenen Host. Ein fremder Formulardienst ist nicht eingebunden.

Nur auf diesem PHP-Host entsteht eine Sitzungscookie, und nur für die Dauer der Browser-Sitzung, um fremde Aufrufe abzuweisen. Die Anwendung schreibt den Nachrichtentext nicht in ein eigenes Protokoll. Die angenommene Nachricht liegt als E-Mail im Postfach info@megacleanberlin.de. Ein Zähler gegen zu viele Anfragen liegt außerhalb des öffentlichen Verzeichnisses. Eine abgelaufene Zählerdatei löscht erst der nächste Aufruf, der das Limit prüft. Ohne diesen Aufruf bleibt sie über eine Stunde hinaus liegen.
